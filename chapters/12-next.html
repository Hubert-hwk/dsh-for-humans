十章的词都收进这张表——下次跟人聊 dsh，你也可以一边点头一边蹦术语，假装资深专家了。 （放心，我们全程都用大白话解释，绝不让你露馅。）

术语速查表

（英文术语保留，中文为官方文档用词 / 本教程释义）

术语一句话章节
Agent（智能体）会思考、会调用工具、有独立会话的执行体01
Harness（马具/框架）让模型能干活的那套装备：工具、记忆、执行环境01
Plugin（插件）功能积木：一段挂载代码，贡献服务/事件/副作用02、03
Context（上下文 ctx）服务的容器，服务按 ctx.<key> 查找03
inject声明依赖：等依赖服务就绪才启动插件03
Waterfall（瀑布式事件）接力棒语义：监听器 next() 委托或拍板短路03
Disposer（释放函数）每个注册的撤销凭证，卸载时自动清理03
Turn（轮次）排空一次已接纳输入的全过程04
Step（步骤）一次模型请求 + 其触发的工具执行04
Inbox（收件箱）agent 的两列待处理消息队列（next-turn / next-step）04
SessionEvent（会话事件）只追加日志里的类型化条目，13 种核心变体05
deriveMessages()从日志投影出模型历史的函数05
Seam（能力缝）接口 + 实现 + 使用方的完整可替换能力06
Provider（提供方）seam 里的实现角色，可整体替换06
Consumer（使用方）注入并使用服务的插件，通常是面向模型的工具06
ToolSchema / execute工具的说明书 / 干活的手07
Guard（单调守卫）只能收窄权限、无法撤销的终审07
Approval（审批）ask → allowed-once 的一次性人类放行07
Spill（溢出）结果太大时落盘，模型只见预览 + 取回指引07
Scope（作用域）按 agent 划分的注册单位，最具体者胜出08
Shadowing（遮蔽）内层同名注册遮住外层，只影响本 agent08
Preset一份 agent.cordis.yml，常驻挂载按会话组装能力08
Subagent（子代理）独立上下文的委派对象，可一次或可延续09
Workflow（工作流）模型编写的 JS 编排脚本，大规模扇出子代理09
Job（后台任务）后台运行的工作，job_list/output/kill 管理09
Skill（技能）复用型指令（SOP），注入提示词而非动作09
Goal Round目标策略的一次续行周期，具体化为一个轮次09
Profile具名组装方案：决定叠放哪些组合包02、10
Bundle（组合包）带拼装说明书的 npm 包（dsh.bundle.patch）02、10
Patch（补丁层）贴纸图层：insert 加行 / 按 id 整块替换 config02、10

一页源码地图

（对照仓库 README.md 里的布局，带你认路）

目录是什么
vendor/vendor 引入的 Cordis 源码（插件框架本体）
packages/core/产品主干：session、system-prompt、tools、agent、agent-loop、scope
packages/llm/模型能力：Service Definition + DeepSeek 提供方
packages/shell/、fs/、web/、subprocess/、terminal/能力缝与提供方：bash、文件、网页、进程、PTY
packages/subagent/、workflow/、jobs/、skill/委派与扩展能力
packages/session/会话持久化、投影、标题、遥测
packages/bundle/dsh-base / web-app / headless 三个官方组合包
packages/boot/启动组装（profile 机制）
apps/CLI 等应用入口
examples/可运行的 cordis.yml 示例（headless-agent、web-cordis……）
docs/架构、子系统、术语表、cookbook（中英双语）
.agents/notes/Agent Notes：每个设计决策的「为什么」

官方资源

  • 源码与发布：github.com/deepseek-ai/deepseek-harness
  • 文档（中英双语）：仓库 docs/，入口 docs/architecture.md、docs/glossary.md、docs/cordis-primer.md

进阶路线（按顺序）

  1. 读架构：docs/architecture.md —— 你已经有本教程的底子，这次能看懂 90%；
  2. 查子系统：docs/subsystems/ —— 每个子系统一页，类型定义 + 语义；
  3. 写插件：docs/cookbook/ —— adding-a-tool / adding-a-package / adding-an-llm-adapter 分步指南；
  4. 跑示例：examples/ —— 把 headless-agent、web-cordis 都跑一遍；
  5. 追决策：.agents/notes/implemented/ —— 每个「为什么这么设计」都有答案；
  6. 贡献代码：读 CONTRIBUTING.md 和 docs/development.md，跑 pnpm run test 等门禁。
